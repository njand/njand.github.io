Production CALL System

Automated Multilingual Language Proficiency Assessment System

Role: Lead ML Researcher & Product Manager
PyTorch mmBERT PEFT / LoRA Praat spaCy Azure ML Studio

The Challenge & Problem

Replaced an expensive legacy vendor system ($300k/year) restricted to only 9 languages that suffered from poor scoring correlation with human OPIc/ACTFL raters (0.36 Quadratic Weighted Kappa).

System Architecture

  • Preprocessing: Azure batch pipeline extracting acoustic features via Praat (pitch, jitter, pause cadence) and syntactic features via spaCy.
  • Modeling Pipeline: Fine-tuned Multilingual Modern BERT (mmBERT) using a 3-stage transfer learning regime with parameter-efficient LoRA adapters per target language.

Validated Production Metrics

Quadratic Weighted Kappa
0.86 (vs 0.36)
Spearman Correlation
0.86 (vs 0.44)
Mean Absolute Error
0.55 (vs 0.68)
Cost Reduction
~75%

Successfully scaled across 70+ languages, enabling zero-shot/few-shot automated scoring for previously un-evaluated low-resource target languages.
