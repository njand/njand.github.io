Automated Assessment System

Automated Multilingual Language Proficiency Assessment System

Role: Lead NLP Research Engineer & Product Manager
PyTorch mmBERT PEFT / LoRA Praat spaCy Azure ML Studio

The Challenge & Problem

Architected an in-house automated scoring pipeline projected to yield $250k+ in recurring annual operational vendor savings (>90% infrastructure cost reduction compared to the legacy vendor system) upon final deployment, while significantly improving human rater correlation.

System Architecture

  • Preprocessing: Azure batch pipeline extracting acoustic and temporal metrics via Praat (rate of speech, pause frequency, pause duration) and syntactic features via spaCy.
  • Modeling Pipeline: Fine-tuned Multilingual Modern BERT (mmBERT) using a 3-stage transfer learning regime with parameter-efficient LoRA adapters per target language.
