Low-Resource Latin Speech Recognition Pipeline

Role: Solo Engineer
PyTorch wav2vec2 pyctcdecode KenLM Optuna ONNX Runtime Modal (Serverless GPU) Weights & Biases CodeCarbon PyPI Package Gradio

Architected an end-to-end machine learning pipeline and post-processing engine for Latin speech recognition (restored classical pronunciation). Built by fine-tuning self-supervised speech representations and transformer sequence labelers across custom datasets.

  • Acoustic Performance: Achieved 12.20% Strict WER / 2.74% Strict CER across 5-fold cross-validation on fine-tuned wav2vec2-xls-r-300m model.
  • LM Decoding & Optuna Tuning: Further reduced acoustic error rates by combining pyctcdecode with a KenLM language model built on an extensive lexicon of fully inflected Latin unigrams. Optimized decoder parameters using optuna.
  • Contextual BERT Rescoring: Implemented a Masked Language Model Pseudo-Log-Likelihood rescoring pass using latin-bert to re-rank candidate beams and resolve ambiguous acoustic predictions.
  • Published PyPI Package for ITN: Packaged and published the post-processor to PyPI (latin-itn). Fine-tuned a 14-class sequence labeler on latin-bert to restore casing and punctuation on raw predictions.
  • Edge Quantization: Exported PyTorch weights to ONNX INT8, yielding a 72% memory reduction (1.26 GB to 355 MB) and accelerating CPU inference speed by ~3x.
  • Serverless MLOps & Telemetry: Automated remote multi-GPU training on Modal (NVIDIA L4 instances) with persistent caching, Weights & Biases experiment tracking, and CodeCarbon emissions logging.

Multilingual Grammatical Error Correction (GEC) & SLA Feedback System

Role: Lead NLP Research Engineer
OpenAI API Pydantic Multi-LLM Benchmarking Few-Shot Prompting Human-in-the-Loop (HITL) Evals Python Automated Quality Gates

Architected an LLM-powered Grammatical Error Correction (GEC) and pedagogical feedback engine targeting novice language learners across 60+ languages. Built an automated multi-model evaluation harness, dynamic prompt engineering pipeline, and educator-driven QA framework to benchmark LLM outputs against strict safety and helpfulness thresholds.

  • Structured Outputs & Automated Few-Shot Curation: Built prompt pipelines that automatically generated and curated few-shot examples for low-resource languages. Enforced strict Pydantic schemas via OpenAI Structured Outputs to guarantee 100% parseability of corrections and explanations.
  • Cross-Model Evaluation Harness: Evaluated multiple LLM models and providers using an automated multi-run execution harness. Ran multi-pass inference over educator-authored 10-sentence paired test sets (correct vs. learner error variants) to account for non-deterministic model behavior.
  • Large-Scale Educator Coordination: Coordinated evaluation workflows with dozens of qualified teachers and tutors across 60+ languages to score model feedback, analyze error patterns, and isolate language-specific failure modes.
  • Iterative Optimization & Global Scale: Systematically iterated on model selection, prompt design, and few-shot examples for failing languages until meeting release criteria—successfully launching GEC feedback across 41 target languages for tens of thousands of active learners.
